Independent Project

SolarSense AI

Clean Energy Analytics & Solar Feasibility Platform

Platform Preview
Problem Statement

Evaluating rooftop solar viability is difficult due to varying utility rate structures and manual calculation audits. SolarSense AI automates this by analyzing electricity bills to generate instant solar recommendations and financial models.

Technical Architecture & Approach

Built with a React.js client and a Node.js / Express.js backend. Generation formulas combine solar irradiance estimates with tariff models to calculate recommended capacity. Applied machine learning basics to evaluate seasonal consumption spikes and suggest load-shifting adjustments.

Tech Stack & Libraries
React.js Node.js Express.js MongoDB ML Basics REST APIs Chart Visualizations
Core Features Built
Electricity Bill Analytics: Automated breakdown of monthly consumption cycles, peak loads, and unit rate brackets.
Interactive Solar Simulator: Instant recalculation of generation yield and monthly savings based on custom roof area and budget.
Financial ROI & Payback: Forecasting break-even horizons, 25-year cumulative savings, and net-metering revenue.
Subsidy Calculation: Identifies applicable central and state government renewable energy subsidies.
Energy Advisory: Algorithmic pattern detection identifying unit leakage and peak load mitigation.
My Engineering Role

Designed dashboard interfaces, programmed tariff computation algorithms, created MongoDB billing schemas, and implemented consumption pattern models.

Internship Project

Alaybee Sports

Full-Stack Athletic Equipment & E-Commerce Platform

Platform Preview
Problem Statement

Sports clubs and athletes often encounter inconsistent inventory visibility and fragmented shopping experiences. Alaybee Sports provides a unified sports equipment storefront featuring categorized catalogs, simulated checkout, and order tracking.

Technical Architecture & Approach

Architected as a decoupled full-stack application with a React 18 (Vite) client and a Node.js / Express.js REST API. Global state is managed with the React Context API across cart items, wishlists, and user authentication.

Tech Stack & Libraries
React 18 Vite Bootstrap 5 Node.js Express.js MongoDB Atlas JWT Auth REST APIs Context API
Core Features Built
160-Product Catalog: Organized across 10 sports categories with a customer review and rating system.
Cart & Wishlist State: Context API state with item quantity controls, subtotal summaries, and instant updates.
Pro Lounge VIP Access: Role-based access with exclusive privileges for registered members.
Simulated Checkout: Multi-step simulated checkout with automated invoice and receipt generation.
4-Stage Order Tracker: Real-time shipment status tracking across order placement, processing, shipping, and delivery.
My Engineering Role

Developed React components with Bootstrap 5, implemented React Context for cart and auth state, created Express.js REST endpoints with JWT guards, and modeled MongoDB collections.
