SolarSense AI

AI-Driven Clean Energy Analytics & Solar Feasibility Platform

Dashboard & Simulation Interface
Problem & Motivation

Evaluating solar rooftop adoption for residential and commercial spaces typically entails costly, opaque feasibility studies and complex mathematical analysis across tier-based utility electricity tariffs, sun irradiance hours, and variable equipment degradation. SolarSense AI solves this by translating raw electricity bills and usage patterns into instantaneous, highly visual, actionable solar viability reports.

Technical Architecture & Implementation

Engineered end-to-end with a decoupled React.js client and Node.js / Express.js backend. Power generation formulas integrate solar irradiation models and tariff brackets to compute recommended kW capacity. Machine learning algorithms and the Gemini API evaluate seasonal consumption spikes and output personalized energy conservation strategies. MongoDB stores scenario simulations and user profile benchmarks.

Tech Stack & Libraries
React.js Node.js Express.js MongoDB Python / ML Gemini AI API REST APIs Data Visualization
Core Features Built
Electricity Bill Analytics: Automated breakdown of monthly consumption cycles, peak loads, and historical unit costs.
What-If Solar Simulator: Dynamic parameter tuning (roof area, capital budget, battery storage) with real-time graph recalculations.
Financial ROI & Payback: Precise forecasting of break-even year, cumulative 25-year savings, and net-metering revenue.
Subsidy Evaluation: Automatic calculation of applicable central and state government renewable energy subsidies.
AI Efficiency Advisory: Generative AI recommendations identifying energy leakages and peak usage mitigation.
My Engineering Contributions

Architected the complete full-stack workflow: created responsive frontend dashboards with interactive data sliders, engineered server-side tariff computation algorithms, designed MongoDB schemas for billing history, and connected AI recommendation endpoints with robust error handling.

Project Match

Student Collaboration, Teammate Matching & Mentor Discovery Platform

Platform Preview & Directory Interface
Problem & Motivation

University engineering students consistently face friction when seeking teammates with complementary technical skill sets for hackathons, capstones, and open-source initiatives. Communications get fragmented across informal chat groups with no structured visibility into skill proficiencies, availability, or project commitments. Project Match creates a dedicated matching ecosystem for student builders.

Technical Architecture & Implementation

Built using a modern React.js (Vite) frontend styled with Tailwind CSS for rapid, responsive component rendering. The backend leverages Node.js and Express.js providing RESTful APIs secured with JWT-based authentication. Multi-criteria filtering queries MongoDB using compound indexes across skill tags, graduation year, and role preferences.

Tech Stack & Libraries
React.js Vite Tailwind CSS Node.js Express.js MongoDB JWT Auth REST APIs
Core Features Built
Student Discovery Engine: Multi-parameter search across technical skills, project domain interests, and availability status.
Role-Based Teammate Matching: Logic designed to match builders by identifying complementary skill gaps (e.g. UI/UX + Backend + Data).
Project Postings & Recruitment: Structured project boards with role definitions, applicant tracking, and status workflows.
Mentor Discovery Hub: Dedicated portal to connect with senior student guides and technical mentors.
Secure State & Sessions: Protected routes, stateless JWT authorization, and parameterized query sanitization.
My Engineering Contributions

Developed the end-to-end full-stack solution: engineered modular React components with Vite, built the Express REST endpoints and route guards, structured MongoDB schemas for users and applications, and implemented the multi-tag filtering algorithm.
