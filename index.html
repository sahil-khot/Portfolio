SolarSense AI

AI-assisted solar feasibility and energy analysis platform

Dashboard Preview
Project Overview

An AI-assisted solar analysis platform that analyzes electricity usage and helps users evaluate solar system size, investment, savings, subsidy impact and payback.

Problem & Solution

Traditional solar assessment requires manual calculations and technical audits that are opaque to consumers. SolarSense AI extracts consumption insights directly from electricity bills, models regional tariffs, and simulates what-if scenarios with immediate payback calculations.

Tech Stack
React.js Node.js Express.js MongoDB AI/ML Models Data Visualization
Key Features Built
Electricity bill analysis
Solar system recommendation
What-if solar simulator
Financial savings/payback analysis
AI-assisted recommendations
My Contribution
