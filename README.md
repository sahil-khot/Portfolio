## 💻 Local Setup & Preview

To run this portfolio locally without any external dependencies:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sahil-khot/Portfolio.git
   cd Portfolio
   ```

2. **Serve locally:**
   Using Python:
   ```bash
   python -m http.server 3000
   ```
   Or using Node (`npx serve`):
   ```bash
   npx serve .
   ```

3. **Open in browser:**
   Navigate to `http://localhost:3000` to view the live experience.
